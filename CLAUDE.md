# quantia-ui-lab
Laboratório de front-end isolado do Quantia Energia App. Responder sempre em português do Brasil.
- Só estático (HTML/CSS/JS, sem build nem dependências); dados sempre fictícios.
- Nunca escrever em outros repositórios. Ler também não, com duas exceções autorizadas pelo Arthur:
  **só leitura** do front-end de `~/projects/quant-energia-app` (15/11/26), para recriar as páginas aqui com dados
  fictícios; e **escrita** no padrão Mesa (18/11/26), que nasceu daqui, só para levar a ele o que for aprovado
  (regras do CLAUDE.md de lá). O padrão está na pasta `quantia-padrao-mesa/` (submódulo git com o repositório
  público): editar lá dentro, commitar e enviar no próprio submódulo e depois atualizar o ponteiro aqui.
  `padrao/` é cópia congelada, não editar: variações vão em `variantes/<NN-nome>/tema.css`.
- Seguir `padrao/GUIA.md` (tokens como variáveis em `:root`, com tema escuro; português com acentuação; números pt-BR).
- Nova variante: copiar `variantes/_modelo` e registrar em `index.html`.
- O formato Mesa (variante 08) virou o padrão `quantia-padrao-mesa` (repositório próprio). Aqui ficam os experimentos;
  o que for aprovado para todos os projetos é levado ao padrão (GUIA, catálogo, núcleo e demo juntos).
